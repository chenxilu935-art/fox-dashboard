# 📐 开发需求 v0.1

## 项目定位

Obsidian 插件形式的个性化工作台首页。替代 Home.md + CSS snippet + JS Engine 架构。

## 核心功能模块

### 1. 视觉层
- 双主题（白天：森林探索者 / 黑夜：独狼观测站）
- 全屏背景图切换
- 玻璃态卡片设计语言（blur + rgba + 渐变边框）
- 响应式：1200/900/768/560 四档

### 2. 信息展示
- Hero 时钟 + 日期 + 每日座右铭
- 统计面板（日志数/连续记录/本月天数/今日目标完成率）
- 最近更新（最后 5 篇笔记）

### 3. 今日任务
- 读取当天和昨天日记的 `- [ ]` 任务
- 点击勾选写入 `- [x]` + 收拢动画
- 输入框添加新任务写入当天日记

### 4. 倒计时
- CRUD 全功能（设置持久化）
- 按剩余天数排序
- 紧急度颜色分级：过期/今天/≤7天/≤30天/普通

### 5. 快速记录
- 多行 textarea 随手记录
- 保存到当日日记末尾

### 6. 今日心情
- 8 张情绪图片（assets/emotions/）
- 选中后写入日记 frontmatter `mood:` + `mood_note:`

### 7. 健康习惯
- 5 项预设习惯勾选（早起/冥想/运动/阅读/日记）
- 写入日记 frontmatter `habits: [早起, 阅读]`
- 环形完成率指示器

### 8. 备考进度
- 设置中配置进度项（名称|当前值|最大值）
- 进度条展示 + 整体统计

### 9. 年度热力图
- SVG 365 天网格
- 日记密度 4 级着色
- 月份标签 + 工作日标签
- 悬停 tooltip

### 10. 第二森林
- 4 张卡片入口：图书馆/电影收藏/长期项目/成长记录
- 点击跳转对应笔记或文件夹
