# 🗺️ 文件地图

## 项目根 `.obsidian/plugins/fox-dashboard/`

### 源码文件（需编译）

| 文件 | 类型 | 行数 | 职责 |
|------|------|------|------|
| `main.ts` | TypeScript | 160 | Plugin 入口，注册视图/设置/命令/图标 |
| `view.ts` | TypeScript | ~1100 | 核心视图，全部渲染 + 数据逻辑 |
| `styles.css` | CSS | ~1200 | 全部样式，双主题变量，响应式 |

### 配置文件

| 文件 | 职责 |
|------|------|
| `manifest.json` | Obsidian 插件元数据（id/name/version/minAppVersion） |
| `package.json` | 依赖管理（obsidian, esbuild） |
| `tsconfig.json` | TS 编译选项 |
| `esbuild.config.mjs` | 打包配置（external obsidian/electron） |

### 编译产物

| 文件 | 职责 |
|------|------|
| `main.js` | 打包后的插件代码（~60KB） |
