## 开发流水线

### 本地开发

```bash
# 1. 修改源码（view.ts / main.ts / styles.css）
# 2. 编译 → 覆盖 main.js
cd .obsidian/plugins/fox-dashboard/
npx esbuild main.ts --bundle --outfile=main.js --external:obsidian --external:electron --format=cjs --platform=node

# 3. 在 Obsidian 中测试：
#    - Ctrl+R 重载全部插件
```

| `view.ts` | 编译 `main.js` |

| `styles.css` | 无需编译，Obsidian 热加载 |
| `manifest.json` | 重启 Obsidian |

## 常用修复模式

### 图标不显示
所有图标路径必须通过 `getAssetPath()` 解析：
```typescript
// ✅ 正确
icon.src = this.getAssetPath('assets/icons/xxx.png');
// ❌ 错误（路径不解析）
icon.src = 'assets/icons/xxx.png';
```

### 主题切换后模块空白
`onSettingsChanged()` 必须调用全部 `load*` 方法，不能只 `this.render()`：
```typescript
onSettingsChanged() {
    this.render();
    setTimeout(() => {
        this.loadStats();
        this.loadTasks();
        // ... 全部 load 方法
    }, 50);
}
```

### SVG 渲染问题
在 Obsidian 插件上下文中，SVG `<rect>` 的 `fill` 属性用 CSS class 控制有时不生效。方案：用 inline `fill`。
```typescript
// ✅ 正确
svg += `<rect fill="rgba(120,155,88,0.56)" .../>`;
// ⚠️ 可能有问题
svg += `<rect class="fox-hm-lvl-2" .../>`;
```
